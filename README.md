# Crystalis — Payroll & Human Resources Management System (HRMS)

Crystalis is an enterprise-grade, full-stack Human Resource Management System (HRMS) and automated payroll processing engine designed to streamline employee lifecycles, attendance tracking, configurable pay runs, and workforce administration.

## System Architecture & Key Modules

### Core Modules & Functionality
* **Employee Information Management:** Centralized directory, lifecycle management, profile history, and document storage.
* **Attendance & Time Tracking:** Configurable shifts, geolocation verification, remote work logging, and manual attendance overrides.
* **Leave & Request Administration:** Granular leave policies (sick, maternity, paternity, hajj, etc.), permission requests, and multi-tier manager/HR approval workflows.
* **Automated Payroll Engine:** Complete payroll cycle execution supporting basic salary, overtimes, lateness penalties, statutory tax brackets, social insurance deductions, and PDF payslip generation.
* **Off-Cycle Payroll:** Support for standalone off-cycle bonus payouts and scheduled deduction calculations.
* **Benefits Administration:** Insurance plans, allowance package assignments, and dependent coverage logic.
* **Recruitment & Applicant Tracking (ATS):** Public job board posting, applicant stage tracking, interview scheduling, and offer/rejection email automation.
* **Performance & Training:** Customizable employees review cycle templates, metric evaluation forms, course management, and training progress tracking.

## Tech Stack

### Frontend
* **Framework:** Angular 20
* **Language:** TypeScript
* **Development & Styling:** CSS, HTML5

### Backend
* **Framework:** Java Spring Boot
* **Build Tool:** Maven
* **Database:** PostgreSQL containerized in Docker
* **Security & Auth:** Spring Security with JWT & Token Blacklisting
* **Email Testing:** Mailpit
* **API Documentation & Testing:** Swagger / OpenAPI, Postman
